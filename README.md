# KurokoCast アップデート情報

このリポジトリは、**KurokoCast** のアップデート確認用データと、インストーラー配布情報を公開するためのリポジトリです。

## KurokoCast とは

**KurokoCast** は、Windows向けのリアルタイム字幕・OCR翻訳・配信補助アプリです。

ゲーム配信、通話、作業配信、海外ユーザーとのコミュニケーションなどで、音声や画面上の文字を字幕・翻訳として扱いやすくすることを目的に開発しています。

主に以下のような用途を想定しています。

* マイク音声をリアルタイムで字幕化
* デスクトップ音声をリアルタイムで字幕化
* Google認識を使った字幕表示
* AI-DLCを使ったローカル音声認識
* 画面上の文字を読み取るOCR翻訳
* 配信画面に載せやすい字幕ウィンドウ表示
* 不具合報告用のサポートZIP作成

現在は正式版ではなく、**プレプレテスト版・ベータ版** として開発中です。

## AI-DLCについて

KurokoCast本体には、ローカルAI認識用の大きなデータは同梱していません。

ローカル音声認識やOCR翻訳など、一部の機能を使用する場合は、アプリ内の案内から **AI-DLC** を追加で導入できます。

Google認識のみを使う場合は、AI-DLCがなくても利用できます。

現在のbeta版では、検証済みの **AI-DLC 0.1.0-ai.2** を使用します。

## 現在の状態

KurokoCast は現在、正式公開前のテスト版です。

そのため、以下の内容は今後変更される可能性があります。

* 機能
* 画面デザイン
* 設定項目
* アップデート方法
* 配布方法
* AI-DLCの構成

不具合や違和感がある場合は、アプリ内のサポートZIPを作成して共有してください。

## 注意事項

* Windows向けのテスト版です。
* 初回起動時に Windows Defender や SmartScreen の確認が出る場合があります。
* AI-DLCの導入には時間がかかる場合があります。
* AI-DLCは容量が大きいため、十分な空き容量がある状態で導入してください。
* 不具合報告時は、可能であればサポートZIPを添付してください。

## このリポジトリの目的

このリポジトリは、KurokoCast本体のソースコード公開用ではありません。

主な用途は以下です。

* アップデート確認用JSONの公開
* プレプレテスト版・ベータ版の配布情報管理
* GitHub Releases によるインストーラー配布
* リリースノートの管理
* AI-DLC配布情報の管理

## 含まれるファイル

このリポジトリには、主に以下のファイルを置きます。

* `latest-beta.json`
* `latest-stable.json`
* 必要に応じたリリース案内

インストーラー本体は、このリポジトリに直接コミットせず、GitHub Releases の Assets として公開します。

## アップデート確認の仕組み

KurokoCast は、このリポジトリにあるアップデート情報ファイルを確認して、新しいバージョンがあるかどうかを判定します。

### ベータ版チャンネル

```text
latest-beta.json
```

### 安定版チャンネル

```text
latest-stable.json
```

## 開発・管理上の注意

このリポジトリには、以下のファイルを置きません。

* KurokoCast本体のソースコード
* 開発用ファイル
* テストコード
* ログ
* サポートZIP
* OCRデバッグ画像
* ローカル設定ファイル
* `.exe` ファイルの直接コミット
